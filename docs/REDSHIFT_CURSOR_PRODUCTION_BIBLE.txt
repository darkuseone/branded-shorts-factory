1. БРЕНД — ИСТОЧНИК ПРАВДЫ (НОВЫЙ ТАРГЕТ)
================================================================================

Имя: REDSHIFT
Древний смысл: «чистое небо» / среда, через которую проходят данные, энергия,
открытия. Современный смысл: фронтир знаний, через который проходит сигнал.

Позиционирование:
  Не «ещё один научпоп». Визуально премиальный, мгновенно узнаваемый голос
  фронтира. Красиво, точно, ощущение «я только что увидел что-то настоящее».

Главная эмоция: тихий восторг + ясность.
Зритель останавливается в ленте НЕ из-за крика, а из-за красоты и «это другое».

Роль ведущего: «Ты — проводник». Живой человек на границе космоса / AI / науки.
Красный = энергия открытия, кровь, срочность прорыва.

================================================================================
3. DEEP REVERSE ENGINEERING РЕФЕРЕНСОВ
================================================================================

Ниже — извлечённые законы монтажа из референсных роликов/кадров канала-образца
(Aleko-like dynamics) + speaking-head студии + мем-банка REDSHIFT.

----- 3.1 Что нравится в «первом» видео (ДИНАМИКА) -----
Наблюдения по dense Aleko remount (~42с, 9:16):

A) Layout map (пример HF/OpenAI ролика):
   0.00–2.00   host_full          хук глазами в камеру
   2.00–8.00   footage_full       смысловые пластины (хакер/сервер/access)
   8.00–10.5   split 50/50        верх=футаж, низ=ведущий
   10.5–18.5   footage_full       новости/графики/серверы
   18.5–21.0   split
   21.0–29.0   footage_full       news cards / literal text plates
   29.0–32.0   split
   32.0–36.0   footage_full       payoff visuals
   36.0–42.0   host_full          вывод + CTA «Подписаться» (~последние 2с)

B) Cut rate:
   - Фото/карточки: 1.2–2.8с (часто ~1.5–2.0с) + ОБЯЗАТЕЛЬНЫЙ motion
     (kenburns / parallax / zoom_in / pan)
   - Видео-пластины: 2.6–4.2с (редко до 5.0с)
   - Split-окна: ~2.0–2.4с
   - Host_full opening: ровно ~2.0с
   - Host_full ending: самый длинный кусок ~5–6с (якорь доверия)
   - Жёсткое правило: НЕ держать одну пластину >4с без причины
     (data-heavy / emotional hold — исключение до 5–6с, максимум 1 раз)

C) Visual storytelling:
   - Meaning-match: фраза про взлом → hooded/hacker / access denied /
     server LEDs / news card «Hugging Face»
   - Цветовые блоки настроения: red=угроза/denied, green=matrix/hacker,
     blue=news/официал, void black=тишина перед ударом
   - News cards: полноэкранные тёмные карточки с badge + крупный тезис
   - Иконки брендов (ChatGPT/HF/NASA): как отдельный beat, не как водяной знак

D) Captions:
   - Белые, низ кадра (bottom), короткие строки
   - Предпочтительный канал-стандарт REDSHIFT: karaoke/word punch на акцентах
     (highlight Crimson), без белых подложек
   - Не перекрывать глаза/рот ведущего

E) Ending:
   - Возврат в host_full
   - Фраза-вопрос или wow-закрытие
   - Badge «Подписаться» последние ~2.0с
   - Опционально: мем-удар ≤1.4с на irony-bit ПЕРЕД финальным вопросом
     или сразу после punchline (не поверх CTA)

----- 3.2 Что нравится во «втором» видео (ГОВОРЯЩАЯ ГОЛОВА) -----
  - Студийный talking-head: грудь+голова, мик, жесты руками у стола
  - Хороший key light + rim; лицо всегда читается на телефоне
  - В REDSHIFT: тот же «якорь присутствия», но в фирменном Deep Void /
    Crimson мире (не копировать чужие purple/cyan неон-стены один-в-один)
  - Ведущий занимает 40–70% кадрового времени суммарно по трём режимам
  - Микро-мимика, моргание, лёгкие повороты головы; без бешеной жестикуляции
    в крупном плане лица (consistency)

----- 3.3 Инфографика / «рисовка как нравится» -----
Целевой язык (не PowerPoint, не Canva-cards spam):

  1) ICON BEAT
     Скачать иконку/логотип субъекта (ChatGPT / Hugging Face / JWST / NASA)
     со стока Magnific/Pixabay или официальный press kit.
     Показать крупно на Deep Void 1.2–2.0с.
  2) RELATION BEAT
     Стрелка / орбитальная линия / «→» / красный pulse-path от A к B.
     Пример: [иконка ChatGPT] —красная стрелка→ [иконка Hugging Face]
     + маленький badge «sandbox escape» / «zero-day».
  3) EVIDENCE BEAT
     Скрин статьи / OG-image / press photo / news card с датой.
     1.5–2.5с, лёгкий kenburns.
  4) MECHANISM BEAT
     Схема: 3–5 узлов максимум (песочница → прокси → интернет → датасет).
     JetBrains Mono для подписей узлов. Одна идея = одна схема.
  5) SCALE BEAT
     Одна жирная цифра (JetBrains Mono + gold/crimson) + короткий VO.
  6) HUMAN BEAT
     Возврат к ведущему (split или host_full), чтобы цифра «приземлилась».

Анти-паттерны инфографики:
  - 12 мелких цифр сразу
  - Белые карточки с тенями «дашборд»
  - Эмодзи-кластеры
  - Текст поверх яркого объекта без затемнения
  - Дешёвый neon-grid на весь кадр

----- 3.4 Мем-банк (что уже лежит в репо) -----
  assets/memes/ + index.json (~70 ассетов):
  - reaction stills (IMG_*.jpeg)
  - короткие mp4 реакции (1.3–6с исходники, в ролике режутся до ≤1.4с)
  - FEW MOMENTS / time_skip
  Теги: вопрос, шок, deadpan, later, irony…
  Beats: hook_punch, misconception, absurd_scale, deadpan_accept,
         reveal_twist, context_end, core1_to_core2

Закон мема (из reverse + meme_policy.py):
  Мем = ПУНКТУАЦИЯ, не контент.
  Не в каждом ролике. Цель: редкая пасхалка (~1 из 4–10 по history gate).
  Медицина/трагедия — бан.
  Не брендировать мем кольцом/палитрой — контраст и есть шутка.
  Вход/выход = фирменный whoosh.

4. ТРИ РЕЖИМА ВЕДУЩЕГО (ОБЯЗАТЕЛЬНЫЙ КОНТРАКТ КАДРА)
================================================================================

Всегда доступны ровно три режима. Они ЧЕРЕДУЮТСЯ на протяжении ролика.
Закадровый голос (NIKITA2) звучит во всех трёх.

┌─ MODE A: HOST_FULL ─────────────────────────────────────────┐
│ Ведущий на весь кадр (грудь+голова / стол+мик).             │
│ Когда: хук 0–2с; эмоциональные тезисы; финал 5–6с.          │
│ Фон: студия/Deep Void / лёгкий particle bed.                │
│ Текст: короткие captions bottom; не закрывать глаза/рот.    │
└─────────────────────────────────────────────────────────────┘

┌─ MODE B: SPLIT (≈50/50) ────────────────────────────────────┐
│ Верх: footage / news / icon / schema                        │
│ Низ:  ведущий (host_bottom)                                 │
│ Когда: объяснение механизма, «смотри сюда», сравнение A/B.  │
│ Длительность окна: 2.0–2.6с типично.                        │
│ Верх никогда не продолжается под лицом (gap ≥40px).         │
└─────────────────────────────────────────────────────────────┘

┌─ MODE C: FOOTAGE_FULL (+ VO) ───────────────────────────────┐
│ Полный кадр футажа/карточки/схемы. Ведущий ИСЧЕЗАЕТ.        │
│ Голос продолжает.                                           │
│ Когда: payoff, evidence, wow-кадр, news card, icon story.   │
│ Длительность: фото 1.2–2.8с; видео 2.6–4.2с.                │
│ Возврат к A или B после 1–3 пластин подряд.                 │
└─────────────────────────────────────────────────────────────┘

Правило чередования:
  Не ставь одинаковый layout back-to-back без причины.
  Паттерн-скелет 42с:
    A(2) → C(6) → B(2.2) → C(8) → B(2.2) → C(8) → B(2.2) → C(4) → A(6)
  Точные границы привязывай к script segments / on_camera флагам.

Связь с кодом:
  - footage_pack.build_dense_cut_list(host_windows=[...])
  - scripts/bake_aleko_master.py → jobs/<id>/broll/aleko-master.mp4
  - timeline/composition: host_fullscreen_box / host_bottom_box / split
  - ring может быть OFF в Aleko-режиме; бренд держится цветом/типо/ритмом.
    Если ring ON (Pulse Ring режим) — см. skills neon-ring + talking-head.

5. СТРУКТУРА СЦЕНАРИЯ (RETENTION FRAME)
================================================================================

| Фаза              | Окно        | Задача                                      |
|-------------------|-------------|---------------------------------------------|
| Hook              | 0–2.5с      | Вопрос / bold claim / mid-action news       |
| Intrigue Bridge   | ~3–12с      | Почему важно; НЕ spoiler всего механизма    |
| Core 1            | середина    | Факт / механика                             |
| Twist / Core 2    | середина+   | Поворот, цифра, сравнение                   |
| Resolution        | last 4–7с   | Вывод + вопрос зрителю / петля              |
| CTA               | last ≤2.5с  | «Подписаться» badge                         |

Правила:
  - Один тезис на Short. Режь ~30% первого драфта.
  - Первая on-screen строка = смысл хука (для muted viewers).
  - Голос стартует в первые 0.5с — без тишины.
  - on_camera=true на hook + ключевых ударах + финале.
  - Запрещено: «Привет», «сегодня поговорим», logo cold-open, slow fade.

Финал-формулы (выбирай одну):
  1) Вопрос: «Как вы думаете, захватит ли ИИ человечество?»
  2) Ирония: «А вы думали, нас что, не захватит AI?»
  3) Loop: последняя фраза рифмует хук
  4) Wow + тишина 0.3с + badge

  1. NASA / JWST / ESA press
  2. Archive / Wikimedia
  3. Stock video туманностей/лабораторий
  4. Magnific cinematic gen по промпт-скелету (§7)

Позиция: fullscreen punch (контраст), whoosh in/out.

Подбор:

  prefer safe_for_science=true, intensity soft|mid
  не повторять тот же file N роликов подряд (history)
