# Brand assets — REDSHIFT

| File | Role |
| --- | --- |
| `brandbook.json` | цвета, шрифты, кольцо, голос, аватар, музыка по рубрике |
| `logo.svg` | неополная орбитальная дуга (бампер / watermark) |
| `fonts/` | локальные woff2 — композиция HyperFrames без внешних запросов |

## Шрифты

- **Inter** — субтитры и UI (есть кириллица)
- **Space Grotesk** — латинские заголовки / бренд-знаки. Кириллицы нет — в CSS стек
  падает на Inter автоматически
- **JetBrains Mono** — цифры и data-плашки

После смены файлов в `fonts/` ничего пересобирать не нужно: `composition.py`
копирует их в `media/` при каждом прогоне.
