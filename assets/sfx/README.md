# Sound bank

Положите сюда короткие звуки (`.mp3`, `.wav`, `.m4a`, `.aac`, `.ogg`, `.flac`).
Пайплайн подбирает их сам под каждый элемент `audio_fx` и ничего не генерирует,
пока в банке есть подходящий звук.

## Как это работает

Имена файлов почти не важны. После того как вы положили новые файлы, прогоните:

```bash
PYTHONPATH=src python -m shorts_factory sfxscan
```

Команда измеряет каждый файл (громкость, момент пика, атаку, хвост, спектр) и
пишет `index.json`. Роли (`impact`, `whoosh`, `riser`, `ui`, `thump`, …)
назначаются по форме волны, а не по имени. Музыкальные лупы и ровный гул
помечаются как `bed` / `drone` и в акценты монтажа не попадают.

На монтаже звук **выравнивается по пику**: если whoosh достигает максимума на
0.8 с, файл стартует на 0.8 с раньше склейки — удар ложится в кадр, а не
после него. Длинные хвосты подрезаются автоматически.

## Что лежит сейчас

- ударные one-shot'ы (kick, snare, tom, rim, claves) → `impact` / `thump` / `ui`
- whoosh / cinematic swells → переходы и райзеры
- калимба / coin pickup → UI-блипы и глитчи
- `konditsioner-gudit-…` → drone, только как эмбиенс (в акценты не идёт)

Пробелы закрываются генерацией через ElevenLabs и результат **сохраняется
обратно в эту папку**, чтобы канал со временем звучал одинаково и без расхода.

## Необязательный ручной `index.json`

Если хотите задать теги руками — можно. `sfxscan` при повторном прогоне
сохраняет ваши `title` и дополнительные теги.

Звуки **нужно коммитить**: GitHub Actions собирает ролик из свежего клона.
