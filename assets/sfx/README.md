# Sound bank

Положите сюда 20–40 коротких звуков (`.mp3`, `.wav`, `.m4a`, `.aac`, `.ogg`,
`.flac`) — те, которые вам нравятся. Пайплайн подбирает их сам под каждый
элемент `audio_fx` в сценарии и ничего не генерирует, пока в банке есть
подходящий звук.

Почему свои звуки лучше генерации: они бесплатны, мгновенны, и повторяющийся
набор звуков — это то, что делает канал узнаваемым на слух.

## Как называть файлы

Достаточно, чтобы тип был в имени — теги берутся из имени файла:

```
whoosh-fast-01.wav      → подходит под "whoosh", "transition", "swoosh"
boom-impact-deep.mp3    → подходит под "impact"
riser-tension-2s.wav    → подходит под "riser"
sub-drop-808.wav        → подходит под "sub_drop"
pop-bubble.wav          → подходит под "pop"
glitch-stutter.wav      → подходит под "glitch"
ui-blip.wav             → подходит под "ui", "click"
```

Синонимы учитываются: файл `boom-…` найдётся по запросу `impact`, `swoosh-…` —
по `whoosh`. Если под один тип подходит несколько файлов, они **чередуются** —
шесть одинаковых whoosh подряд в одном ролике не получится.

## Необязательный `index.json`

Если имя файла неудобное, задайте теги явно:

```json
{
  "items": [
    {
      "file": "sig_hit_v3.wav",
      "title": "Фирменный удар",
      "tags": ["impact", "brand"],
      "duration": 1.2
    }
  ]
}
```

`duration` полезен: он точнее, чем значение из сценария.

## Что попадает в генерацию

Если под какой-то `audio_fx` в банке ничего нет, этот звук (и только он)
генерируется через ElevenLabs. В отчёте у каждого эффекта видно `source`:
`library` или `elevenlabs`. Хотите нулевой расход — закройте банком все типы,
которые используете в сценариях.

Аудиофайлы не коммитятся в git (см. `.gitignore`) — только этот README и
`index.json`.
